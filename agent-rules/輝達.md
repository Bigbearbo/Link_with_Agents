# 大哥給輝達的規則（Claude 維護；輝達只能讀、不能改；每次修改進 git，附改前改後評分）
摘要：研究想法庫 007「大哥改小弟」——輝達卡住時由強模型讀它的失敗紀錄、改這份規則，讓它本身變強，而不是代做。
更新：2026-11-17 23:55｜版本 1

## 規則 1：先構造、再搜尋（2026-11-17，依據：carry 78%、detect_zero 93.75% 卡在 {-1,0,1} 權重搜尋）
- 能寫成「加權和有沒有過門檻」的功能（比大小、進位、是否為零、某位是 1），先**直接算出權重**：
  例如 4 位元 a+b 是否進位（≥16）＝ 單元權重 a 的四位各 1,2,4,8、b 同樣 1,2,4,8，門檻 16。
  是否為零＝ 所有位權重 −1、門檻 −0.5（全 0 時才過）。
- 只有想不出構造時才用搜尋；搜尋不要把權重限制在 {-1,0,1}，整數或實數都可以。
- 單層做不到的（例如 XOR、模加法的低位），先說明為什麼（不是線性可分），再加一層隱藏單元，每個隱藏單元各自是一個門檻判斷。
